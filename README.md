# China Stopover Guide

A comprehensive web application designed to assist foreign tourists traveling through China with a stopover visa by providing personalized travel reports, general travel guidance, and emergency resources.

## Features

### 1. Personalized Travel Reports
- Generate customized travel plans based on your stopover duration, interests, and budget
- Input your travel details and receive AI-powered recommendations
- Download or print your personalized report

### 2. Travel Guide
- Access comprehensive information about China's culture, attractions, and customs
- Browse through categories including visa information, payment methods, food, transportation, communication, and cultural tips
- Search for specific topics within the guide

### 3. Emergency Resources
- Quick access to emergency contacts and important phone numbers
- Step-by-step guidance for common emergency situations (lost passport, medical emergency, theft)
- Information about embassies, consulates, and international hospitals

## Technology Stack

- **Frontend**: React.js with Chakra UI for a responsive and accessible interface
- **Routing**: React Router for seamless navigation between modules
- **Styling**: Custom theme with Chakra UI components for a modern, clean design

## Getting Started

### Prerequisites
- Node.js (v14.0.0 or later)
- npm (v6.0.0 or later)

### Installation

1. Clone the repository
```
git clone https://github.com/yourusername/china-stopover-guide.git
```

2. Navigate to the project directory
```
cd china-stopover-guide
```

3. Install dependencies
```
npm install
```

4. Start the development server
```
npm start
```

5. Open your browser and visit `http://localhost:3000`

## Usage

1. **Home Page**: Navigate to the three main modules from the homepage
2. **Travel Report**: Fill out the form with your travel details to generate a personalized report
3. **Travel Guide**: Browse through different categories or search for specific information
4. **Emergency**: Access emergency contacts and step-by-step guidance for emergency situations
